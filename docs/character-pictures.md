# Character pictures and Morph Studio

Character Studio keeps ordinary character pictures separate from expression images used by Morph Studio.

## Add character pictures

1. Open **Studio → Characters** and edit a saved character. New characters need to be saved before the picture gallery is available.
2. Click the **+** picture tile to select one or more images.
3. The first picture in the gallery is automatically the **default portrait**. You do not need to select a default manually.
4. Remove a picture with the **×** in its upper-right corner. If you remove the first picture, the next picture becomes the default.

The compact gallery shows **up to three pictures**, followed by the **+** tile and the light-green **MORPH STUDIO** tile. Additional pictures are not deleted or hidden from storage.

## Picture archive

Click **Visa bildarkiv** (Picture archive) below the thumbnails to open the full collection. The archive lets you:

- See all ordinary character pictures, not just the first three.
- Add more pictures with **+**.
- Remove a picture with **×**.
- **Drag and drop** pictures to reorder them. The first picture becomes the default portrait.

Close the archive to return to Character Studio. The main gallery reflects the new order.

## Morph Studio

Click the large, light-green **MORPH STUDIO** tile next to the **+** tile. Morph Studio is a separate editor for **expression images** such as happy, shy or flirty. It opens even if no expressions have been added yet.

- Use **Upload more images** inside Morph Studio to add expression images. Their filenames become initial expression names.
- Select source and target expressions below the corresponding images.
- Adjust mesh points and eye regions, preview the transition with **Play** and **Transition**, and use **Save draft** or **Save profile** in the top-right corner.
- Existing expression images remain separate from ordinary pictures in the picture archive. The Morph Studio tile shows the number of stored expression images.

**Save draft** retains the editor profile without activating it. **Save profile** marks the morph profile active, but automatic morph playback during chat is not connected yet.

## Existing pictures

Older characters may already have a portrait even if they have never used the new gallery. That portrait is shown as the first picture. Existing expression images and saved morph mesh data are retained separately. Removing an ordinary picture does not remove expression images.

Pictures and morph profiles are saved locally in the browser's IndexedDB. Back up your browser data before clearing site storage or moving to another browser.
