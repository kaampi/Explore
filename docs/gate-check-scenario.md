# Gate check pilot

Home → With rules → Try the gate scenario creates an independent conversation. The traveller has Persuasion 60/100 and meets Mara outside a closed city gate. In chat, Take a chance · Roll dice opens the action dialog. Normal difficulty succeeds on d100 ≤ 60; easy adds 20 to the target, hard subtracts 20, clamped to 0–100.

The code resolves one roll before animation. Percentile dice display that result; WebGL failure or reduced-motion preference displays the same number without animation. Collision sound can be disabled; the preference is remembered. Continue the story sends the check to the conversation engine. The target must still be present and the stat and difficulty must still match. The result is saved on the player turn, shown in the transcript, and preserved when a reply is regenerated or replayed. The older trust/favor roll is suppressed for that checked action.

This pilot resolves a narrative interaction. It does not implement a persistent gate object, automatic travel through the gate, combat, damage, or a general consequence editor. An existing local AI connection is required for the guard's generated response; dice resolution itself is local. The scenario does not modify shared character or ruleset libraries.

The restored dice implementation comes from the existing action-check test branch, rather than a merge of that branch's older application files. Legacy `here` character positions are anchored on session loading so NPCs do not follow later player movement merely through an unresolved placeholder.

The gate pilot now uses an authored engine response for the actual yes/no decision: success explicitly opens the gate and permits entry; failure keeps it closed. This prevents a generated reply from leaving a resolved check undecided. The traveller is not moved automatically. This is deliberately scenario-specific, not a universal hard-coded response for all checks. Ordinary conversation afterward is generated by the configured AI. Reloading an open conversation restores the play view in the same browser tab; My conversations also retains previous tests.
